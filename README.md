# Anime Recs

A Flask web app for anime recommendations. Currently a minimal starting point — the server serves a placeholder homepage.

## Requirements

- Python 3.9+
- Flask

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install flask
```

## Running

```bash
python main.py
```

The app runs in debug mode at `http://127.0.0.1:5000/`.

## Project Structure

```
main.py            # Flask app entry point
templates/          # HTML templates
static/              # Static assets (CSS, JS, images)
docs/                # Project documentation
```
